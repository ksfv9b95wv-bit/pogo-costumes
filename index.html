Costume list and dates

Built from Bulbapedia, the community Pokémon encyclopedia, whose text is shared under CC BY-NC-SA 2.5. Some 2026 additions were checked against public event news.

Pokémon pictures

Standard and shiny pictures come from PokeAPI sprites, also served through jsDelivr. Exact costume pictures come from PokeMiners pogo_assets.

Shiny, Lucky and Shadow lists

Loaded live from PoGoAPI. Some newer releases may be missing.

What's new

v13: Pokédex, Regional forms, Mega, Gigantamax, Legendary & Mythical, Purified, 100%, XXL and XXS lists. v12: Events, Community Days and Raid bosses pages; lists now load faster from saved data and Shiny shows where each can be found. v11: works offline, desktop layout, text size. v10: many more exact costume pictures, Floragato picture fixed. v9: this credits page. v8: Shadow list. v7: separate colours for Shiny and Lucky. v6: home screen with four lists. Works offline once opened, and can be installed to the Home Screen.

Report a problem

Wrong costume, missing Pokémon or a bug? Tell us on GitHub (free GitHub account needed).

Events, raids and data

Events come from ScrapedDuck, a feed of LeekDuck events. Raid bosses and the Pokédex data come from pokemon-go-api. Community Days and the Shiny, Lucky and Shadow lists come from PoGoAPI. The data refreshes automatically each day.

Design

Colours and layout are inspired by the in-game Pokédex. The app icon and menu symbols were drawn for this project. Built with help from Claude, made by Anthropic.
